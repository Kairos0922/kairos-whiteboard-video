# 主题包

跨期复用轴只有主题：画风、角色定妆、手笔素材。引擎不认识任何固定主题名。

现役主题以 `registry.json` 为准。只有通过宿主模型探针验证、完成风格冻结的主题才能进入 registry。

## 主题适用场景

| Theme | 定位 | 适用场景 |
| --- | --- | --- |
| `chalkboard-chibi` | 黑板粉笔 Q 版讲解 | 技术原理、科学知识、概念拆解、因果/流程/结构/数据关系、需要清晰解释抽象概念的科普教育 |
| `warm-pencil-family` | 温暖彩铅家庭讲解 | 亲子与家庭生活、心理与行为习惯、生活方式与社会观察、人物关系和日常情境驱动的通俗解释、轻量科普与人文内容 |

主题选择原则：**先判断内容的视觉语义，再选择主题；不要为了复用默认主题而强行迁就内容。**

### warm-pencil-family 状态

`warm-pencil-family` 当前是候选主题，已完成主题包、角色契约和固定 Probe 定义，但尚未完成宿主模型 Probe 验证，因此暂不进入 `registry.json`，也不作为正式发布主题。
